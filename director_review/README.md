# director_review — Pasta Canônica de Decisões do Diretor (Bruno)

Toda imagem que exige veredito do Bruno é entregue aqui em uma subpasta datada:

`director_review/<YYYY-MM-DD>_<nome>/`

Conteúdo obrigatório de cada subpasta:
1. A(s) imagem(ns) de decisão (ex.: captura de zona do blockout C2, kit C3, câmera C4 ou herói C5).
2. `LEIA-ME.txt` com exatamente 3 linhas:
   - `O QUE É: ...`
   - `O QUE VOCÊ DECIDE: ...`
   - `O QUE ACONTECE DEPOIS: ...`

**Regra 6d:** Fixtures e capturas puramente de engenharia/validação ficam em `evidence/` e nunca são enviadas para esta pasta.
